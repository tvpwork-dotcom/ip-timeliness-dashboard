ใช้การกรอกอีเมลด้วยตนเองแทน
ต้องกรอก GitHub Personal Access Token ก่อนนำเข้า/รีเซ็ตข้อมูล เพื่อบันทึกผลถาวรไปที่ไฟล์ dashboard-data.json บน GitHub ให้ผู้ใช้ทุกคนเห็นข้อมูลเดียวกัน (แนะนำสร้างแบบ Fine-grained จำกัดสิทธิ์เฉพาะ Repo นี้ ให้สิทธิ์ Contents: Read and write เท่านั้น) — Token จะถูกเก็บไว้ในหน่วยความจำของเบราว์เซอร์นี้เท่านั้นระหว่างที่ใช้งาน ไม่ถูกบันทึกลงไฟล์ หากไม่กรอก Token การนำเข้า/รีเซ็ตจะยังทำงานได้แต่เห็นเฉพาะหน้าจอนี้เท่านั้น (จะหายไปเมื่อรีเฟรช และคนอื่นจะไม่เห็น)
ไฟล์ที่นำเข้าต้องมีคอลัมน์ครบตามต้นฉบับ (ดู Data Model & Field Mapping ด้านบน) ระบบจะตรวจสอบชื่อคอลัมน์ทุกครั้งก่อนนำเข้า โดยไม่สมมติ Mapping เอง และจะอัปเดตทับเฉพาะเดือนที่ซ้ำ (ตามคอลัมน์ "เดือนที่ส่ง") ส่วนเดือนใหม่จะถูกเพิ่มเข้าไปในชุดข้อมูลโดยอัตโนมัติ — KPI/กราฟ/ตาราง/Insight ทั้งหมดจะคำนวณใหม่ทันที
🔑 จัดการสิทธิ์ผู้ใช้ (เฉพาะผู้ดูแลระบบ)
เพิ่ม/ลบ Gmail ที่อนุญาตให้นำเข้าข้อมูลได้ — การเปลี่ยนแปลงจะถูกบันทึกลง Repo บน GitHub (ไฟล์ approved-emails.json) ผ่าน GitHub API และมีผลกับทุกคนที่เปิด Dashboard นี้โดยอัตโนมัติ (ใช้เวลาประมาณ 1 นาทีให้เว็บไซต์ Build ใหม่)
ต้องใช้ GitHub Personal Access Token (แนะนำสร้างแบบ Fine-grained จำกัดสิทธิ์เฉพาะ Repo นี้ ให้สิทธิ์ Contents: Read and write เท่านั้น และตั้งวันหมดอายุสั้นๆ) — Token จะถูกเก็บไว้ในหน่วยความจำของเบราว์เซอร์นี้เท่านั้นระหว่างที่ใช้งาน ไม่ถูกบันทึกลงไฟล์หรือส่งไปที่ใดนอกจาก GitHub API โดยตรง
